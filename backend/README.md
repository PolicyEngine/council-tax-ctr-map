# Live Calculation Backend

The checked-in frontend is static and reads generated data from `public/data`.
For arbitrary household inputs, the intended production path is a small Modal
API that imports the same PolicyEngine UK CTR branch and returns the same
variables generated by `scripts/generate_static_data.py`.

The static dataset is deliberately the oracle: it lets the frontend, PolicyEngine
UK PR, and any future Axiom implementation compare against the same generated
examples before switching users to a live endpoint.
